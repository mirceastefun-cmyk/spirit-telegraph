# 🕯️ Spirit Telegraph

**Knock twice if you can hear me.**

Spirit Telegraph is a free, open-source web app that turns one reliable movement (a knock, a blink, or a single switch) into text and speech. It resurrects Morse code and the knock (tap) code for people who can't speak or type: people living with ALS, locked-in syndrome or cerebral palsy, stroke survivors, and patients who temporarily can't speak.

> 🎃 Built with [Kiro](https://kiro.dev) for the **Kiroween 2026** hackathon, category **Resurrection**.

## Features (planned)
- Yes / No with one or two signals (knock, blink or switch)
- Help alarm (SOS)
- Spell messages in Morse code (one switch or two switches) or tap code
- Word prediction in English and Romanian, with Romanian diacritics restored
- Text-to-speech, quick phrases and a large caregiver view
- Practice mode
- Private by design: the camera and microphone are processed on your device, and the app works offline
